# Overlink

A private computer workspace for connecting AI assistants to your paired Windows computers.

## What Overlink does

- **Coding:** inspect projects, run coding tasks and tests, and track job results.
- **Web scraping:** extract content from rendered pages with selectors and pagination.
- **Computer tools:** work with files, browser sessions, and terminal commands through a paired computer.
- **App integrations:** use supported adapters, including GitHub and Obsidian, when configured and connected.

Availability depends on the paired computer being online and the required integration being connected.

## About this repository

This is the public product overview for Overlink. It contains only this README and the Overlink logo.

The application source code is maintained in a separate private repository. This repository does not provide downloads, installation credentials, or access to any Overlink workspace or paired computer.

## Access

Overlink is currently a private workspace. Publishing this overview does not make the application or its connected computers publicly accessible.
